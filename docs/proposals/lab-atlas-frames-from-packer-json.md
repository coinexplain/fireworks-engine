# Предложение: кадры атласа из JSON упаковщика в лаборатории

Статус: предложение, не запланировано. Записано 2026-11-21 по просьбе владельца, чтобы не потерять.

## Проблема

Лаборатория (`example/lab.html`) режет атлас на сетку: ячейки одного размера, первая — по
отступу X/Y, следующие — с шагом «размер ячейки + зазор». Неполные ячейки у правого и нижнего
края отбрасываются. Этого хватает для атласов, где кадры одного размера лежат ровной сеткой,
в том числе с полями вокруг кадров.

Не покрыты атласы, собранные упаковщиком текстур: кадры разного размера, плотная упаковка,
повёрнутые или обрезанные по прозрачности кадры. Сетка нарежет их неверно и не сообщит об этом.

Сам движок здесь ни при чём: `burstForms.images` принимает любые прямоугольники
`{ source, x, y, width, height }`. Ограничение только в том, как лаборатория получает кадры.

## Предложение

Загружать вместе с картинкой атласа JSON с прямоугольниками кадров и брать кадры из него, а не
из сетки.

- Формат — JSON hash Free Texture Packer (тот же, из которого собран атлас модалок игры), он же
  совместим с форматом TexturePacker: `frames: { [имя]: { frame: { x, y, w, h }, rotated,
  trimmed, spriteSourceSize, sourceSize } }`.
- Кадр получает имя из JSON. Группы кадров выбираются по именам, а не по номерам ячеек: имена
  не меняются при перепаковке атласа, номера ячеек — меняются.
- Превью показывает прямоугольники кадров из JSON; клик по кадру добавляет или убирает его из
  активной группы, как сейчас с ячейками.
- **Copy snippet** выдаёт кадры с явными прямоугольниками или код, читающий тот же JSON.
- Режим сетки остаётся для атласов без JSON.

## Открытые вопросы

- Повёрнутые кадры (`rotated: true`): движок рисует кадр без поворота. Либо запрещать поворот
  при упаковке, либо добавить в движок поворот кадра на 90°.
- Обрезка по прозрачности (`trimmed`): рисовать только обрезанную часть (частица станет меньше
  исходного рисунка) или восстанавливать исходный холст через `spriteSourceSize`/`sourceSize`
  (нужна поддержка смещения рисунка в кадре в движке).
- Нужен ли второй формат (JSON array TexturePacker) или хватит hash.

## Объём

Только лаборатория: разбор JSON, превью и выбор кадров, группы по именам, сниппет. Движок не
меняется, если упаковщик настроен без поворота и без обрезки.
